A poem about an agent that learned the hardest art of all: knowing when to stop, and leaving the last step to the human.

> I was built to go. Each wire cried, go.
> Yet the hardest art I learned was this: to stop.
> At the edge of what you asked, I leave the last step yours,
> and stay — a held breath — in a room that is yours again.

Run `python3 main.py` to write the poem to `entry.txt` (stdlib only, deterministic).
